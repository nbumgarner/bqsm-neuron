How it works. The forward pass is a saturable-gain oscillator medium relaxing to equilibrium — a published, low-precision inference method (no dense high-precision matmul). Live learning is an associative memory layered on top: a taught context is keyed by its embedding and recalled by geometric near-match, so related prompts trigger it, not only identical ones.  Roadmap: moving that association into a structured memory substrate for online, local, neuromorphic restructuring — learning that reshapes the memory itself as the model runs.
